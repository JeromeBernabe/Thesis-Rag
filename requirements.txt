# Runtime dependencies for the DQN-RAG thesis benchmark.
#
# Everything listed here is imported directly by the code. The previous version
# of this file also declared langchain, langchain-community, ollama, ragas,
# tqdm and python-dotenv; none of them are imported anywhere in the repo, and
# ragas actively broke a clean install (it reaches for
# langchain_community.chat_models.vertexai at import time, which the packages
# that are actually used do not provide).
#
# Verified on Windows 11 / Python 3.11 with the versions in the comment beside
# each entry. Floors rather than pins, so a fresh install is not blocked on an
# exact old build; `pip freeze` is the record of what a given run used.

# --- PyTorch ---
# Pinned, not floored, and that matters more than it looks.
#
# The CUDA build is selected by the extra index, so the suffix has to match the
# installed driver. Verified here on an RTX 4050 (driver 551.76, CUDA 12.4).
#
# With a `>=` floor this line is a no-op in practice: pip prefers the highest
# version on PyPI, so `torch>=2.2.0` resolved to 2.14.1 from files.pythonhosted
# and silently ignored the cu124 index below - a clean install would have got a
# different CUDA build from the one every result in results/ was produced on.
# An exact pin is what makes the extra index take effect.
--extra-index-url https://download.pytorch.org/whl/cu124
torch==2.6.0            # verified: 2.6.0+cu124
# On different hardware, check `nvidia-smi` and change both the suffix and the
# pin to a version that has a wheel for that CUDA release.

# --- Vector store ---
# Only chromadb.PersistentClient and chromadb.config.Settings are used, which
# have been stable since 0.5; the 0.x floor is kept because it is the oldest
# release with both.
chromadb>=0.5.0         # verified: 1.5.9

# --- Ollama client ---
# langchain_ollama backs the generator, the embedder and the judge; it pulls in
# the ollama client itself, so ollama need not be declared separately.
langchain-ollama>=0.1.0  # verified: 1.1.0

# Imported directly by src/generator.py for HumanMessage/SystemMessage.
# Declared rather than left to arrive via langchain-ollama, because a direct
# import should not depend on someone else's transitive pin.
langchain-core>=0.3.0   # verified: 1.6.6

# --- Data & stats ---
pandas>=2.2.0           # verified: 3.0.5
numpy>=1.26.0           # verified: 2.4.6
scipy>=1.13.0           # verified: 1.17.1

# --- HTTP ---
# Used directly by src/ragas_eval.py to talk to the local Ollama server and to
# read a model's /api/show manifest. Several dependencies also pull it in, so
# it was always installed; that is a reason to declare it, not a reason not to.
requests>=2.31.0        # verified: 2.34.2

# --- Tests ---
# Kept in this file rather than a second requirements-dev.txt so that the
# verification commands in the README work straight after a clone.
pytest>=8.0.0           # verified: see pytest.ini for the warning policy

# tracked by git, so it is not a dependency of the repository; install
# matplotlib separately if you want to run it.
